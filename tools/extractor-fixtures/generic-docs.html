Getting started

Install the tool with your package manager, then run it once in your project folder to write its configuration file.

The configuration file lists the folders to watch and the commands to run when a file in them changes. Every option is described on the configuration page.

First run

Run tool init. It asks two questions and writes tool.toml. Then run tool watch and edit a file to see it work.
